# ค่าคาดหวังของข้อมูลสังเคราะห์

`sample.xlsx` เป็นชุดอ้างอิงสำหรับ integration test ข้อมูลทั้งหมดสมมติและไม่มีชื่อบริษัทหรือบุคคลจริง สร้างโดย `scripts/generate-sample.js` ด้วย seed **0x000A0D17** จำนวน **2,000 แถวข้อมูล** บวกหัวตารางหนึ่งแถว ยอดรวมหลังแปลงข้อความจำนวนเงินตามกติกาเท่ากับ **90,853,457.80 บาท** (9,085,345,780 สตางค์)

ค่าด้านล่างมาจากแผนปลูกข้อสังเกตและข้อมูลจำนวนเงินที่ตัวสร้างกำหนด ไม่ได้คัดลอกผลจากฟังก์ชันตรวจ ตัวเลขชุดเดียวกันใน `EXPECTED.json` ใช้ตรวจ regression

| --- | --- | --- |

## แผนเลขที่เอกสาร

สร้างเลขส่วนท้าย 0001–1995 แล้วเว้นเจ็ดเลขที่ระบุไว้ ทำให้เหลือต้นฉบับ 1,988 แถว จากนั้นต่อท้ายสำเนาเอกสาร 0001–0012 อีก 12 แถว จึงได้ทั้งหมด 2,000 แถวและยังคงช่องว่างเจ็ดเลขไว้

สำเนาสี่แถวแรกเปลี่ยนเฉพาะรูปแบบเลขที่: แถว 1990 ใช้ `pv-2569-0001`, แถว 1991 มีช่องว่างหัวท้าย, แถว 1992 มี NBSP ท้ายข้อความ, แถว 1993 มี `U+200B` ก่อนส่วนเลข 0004 ส่วนสำเนาอีกแปดแถวมีค่าเลขที่เหมือนต้นฉบับ ตัวพิมพ์เล็ก/ใหญ่เพียงอย่างเดียวไม่สร้างข้อสังเกตอักขระ

## ข้อความจำนวนเงินที่ปลูกไว้

| แถว | ค่าเดิม (แสดงอักขระพิเศษด้วยชื่อ) | ค่าหลังทำความสะอาด |
| --- | --- | --- |
| 152 | ช่องว่าง + `1,234.56` + ช่องว่าง | 1234.56 |
| 153 | `2,345.67` | 2345.67 |
| 154 | NBSP + `3,456.78` + NBSP | 3456.78 |
| 155 | `4` + U+200B + `567.89` | 4567.89 |
| 156 | `๕๖๗๘.๙๑` | 5678.91 |
| 157 | `6789.12` เป็น text cell | 6789.12 |
| 158 | `(7,890.23)` | -7890.23 |
| 159 | `8,901.34` + U+FEFF | 8901.34 |
| 160 | `+9012.45` | 9012.45 |

ยอดนับสิ่งที่พบเป็นรายฟิลด์: ตัวเลขข้อความ 9, ช่องว่างหัวท้าย 4, comma ในข้อความจำนวนเงิน 5, NBSP 2, zero-width 3 และเลขไทย 1 หนึ่งแถวพบได้หลายชนิด จึงรวมยอดนี้เป็นจำนวนแถวไม่ได้ จำนวนเงินพื้นฐานมีสตางค์ไม่เป็นศูนย์ จึงไม่เข้าเกณฑ์จำนวนเงินกลมโดยบังเอิญ บางแถวเป็นยอดติดลบเพื่อแสดงการรองรับยอดกลับรายการ

## XLSX และ CSV

XLSX เก็บชนิด numeric/text cell ที่ตั้งใจปลูกไว้ CSV ไม่มี metadata นี้ ดังนั้นการนำเข้า CSV อาจได้ยอดนับข้อความจำนวนเงินต่างกันตามการตีความของตัวอ่าน ทั้งคู่มีเลขเอกสาร วันที่ ข้อความ และค่าตัวเลขชุดเดียวกัน แต่ **ค่าคาดหวังการตรวจชนิดเซลล์ข้างต้นอ้างอิง XLSX**

ตารางวันหยุดถูกปล่อยให้ไม่มีวันที่ยืนยันเพื่อไม่สร้างวันที่จากความจำ การเติมวันหยุดจริงที่ผ่านการตรวจแหล่งทางการอาจเพิ่มจำนวนข้อสังเกต calendar ในตัวอย่าง จึงควรใช้สำเนาตาราง placeholder เริ่มต้นเมื่อทดสอบค่าคาดหวังชุดนี้
